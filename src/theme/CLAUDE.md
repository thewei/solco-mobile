# theme/
> L2 | Parent: ../CLAUDE.md

Members:
- `tokens.ts` — the one visual authority (T3 Code's palette in both appearances, DM Sans, Tabler icons; value source `designs/mobile-t3-redesign/src/kit.mjs` `THEMES`): `palettes` (`dark` / `light`, one object each; the shared roles come from `tokens.generated.ts`, the phone-only ones sit beside them), `setActiveScheme` / `activeScheme`, `themed(() => …)` (a lookup table that reads the live palette again on every access) and `colors` (same names as before, but each property reads the ACTIVE scheme when used: read it inside a component or function, never freeze it in a module-level constant — a guard test walks the sources for that; chrome / canvas / surface / surfaceRaised / menu, accent + accentText + accentSoft + onAccent, attention / success / danger, rowPressed, terminal), `radii`, `spacing` (screen gutter 17.5), `type` (the type scale: micro … display), `fontFamilies` (one DM Sans family name per weight — RN on Android picks a font by family name), `metrics` (touch 44, bar button 48), `icons` (size steps by role), `tile`, `row`, `motion`, `monoFont`, breakpoints and the Agent status colors. The phone follows the system or the person's choice (Settings → Appearance); the root layout sets the scheme before any child renders and remounts the screens when it changes.
- `tokens.generated.ts` / `icons.generated.ts` — generated by solco's `design/gen.mjs` from `design/tokens.json` + `design/icons.json` (`rolesDark` + `rolesLight`; the desktop and phone share one role table and one icon registry, 2026-11-07 design-language decision); never hand-edited. `tokens.ts` spells its own names over the shared roles and touch radii; `pnpm check:tokens` is the read-only drift check.
- `tokens.test.ts` — pins the palette against the design kit, the type scale, the role-based icon sizes and the rule that no screen uses `accent` as text color or imports lucide / the Tabler package root.
- `glyphs.ts` — the only module importing `@tabler/icons-react-native` (one file per icon: the package root would bundle ~6,000); screens take a glyph from here and draw it through `components/icon`.
- `fonts.ts` — `useAppFonts`: loads the three DM Sans weights; the root layout keeps the splash up until it answers.

Rule: every screen consumes these tokens; no inline hex/size/radius for what a token already names, and no second terminal palette.
