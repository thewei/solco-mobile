# components/

Members:
Frame and chrome (designs/mobile-t3-redesign `kit.mjs` is the visual source; every size below lives in `theme/tokens`):
- `screen.tsx` — `Screen` (the chrome band with the app bar over a rounded content card — the one page frame; `back`, `title`/`subtitle`, round icon `actions`, custom `bar`, `overlay` for a sheet whose text field needs this window's keyboard hooks), `AppBar`, `BarButton` (48 dp). Native-stack headers are off for every route: a page that is not full-bleed (Remote Desktop's live session, the Terminal's own surface aside) draws through `Screen`.
- `bottom-nav.tsx` — `BottomNav`, the four-tab bar (Chats · Sessions · Usage · Settings, 80 dp, Material 3 indicator); a tab whose capability the Host lacks leaves.
- `menu.tsx` — `Menu` (the 250 dp dropdown under the bar's right edge), `MenuItem`, `MenuRule`, `MenuHeading`: the one popover (Chat's ⋮, the Chats filter, Workspace ⋮).
- `option-sheet.tsx` — `OptionSheet`, the one modal bottom sheet (grabber, title, subtitle, body) of every picker/form sheet.
- `fab.tsx` — `Fab` + `useFabCollapse` (Chats' "New chat"). `toast.tsx` — `useToast()`, the one confirmation chip. `banner.tsx` — `Banner`, the inline "something is off" strip with a retry (optional glyph; Chats' Feedback line uses the inbox). `empty-state.tsx` — `EmptyState`, the one "nothing here / could not load" face (optional spinning glyph). `route-notice.tsx` — the one banner that says the network path changed (Direct ⇄ Relay ⇄ P2P), ~3.5 s, tap to dismiss; text from `state/route-notice-store`. `error-boundary.tsx` — recoverable render failure boundary.
- `icon.tsx` — the only way a screen draws an icon: `Icon` (a Tabler glyph from `theme/glyphs` at the size/tone steps of `theme/tokens`) and `IconTile` (the glyph on a tinted tile). No screen passes its own size, color string or stroke.
- `fill-key.ts` — `fillKey`, the `key` of a rounded View (or `Tap`) whose fill flips transparent ⇄ colour: Android (RN 0.81) would otherwise redraw it square (bottom-nav indicator, launch `Chip`, Remote Desktop dock/segmented). `tap.tsx` — `Tap`, the one press feel (scale + a fade). `pill-button.tsx` — `PillButton` (primary / tonal / soft / danger, optional glyph, compact/fill, md 44 / lg 48): the app's one call to action. `segmented.tsx` — `Segmented`, the two-or-three-way view switch (Review's Unstaged / Staged). `meter.tsx` — `Meter`, the usage gauge. `search-field.tsx` — `SearchField`, the search box that takes the bar's place.
- `list-group.tsx` — the list vocabulary: `Section` (title over one grouped fill, footer), `ListRow` (glyph/leading, label, description, detail, `checked`, chevron), `SwitchRow` (platform Switch for toggle settings), `Shelf`, `MoreButton`, `Hint`; no dividers inside a group.
- `section.tsx` — `SectionLabel` (muted sentence-case caption) and `Card` (the grouped `surfaceRaised` fill of the detail pages — Assistants, Automations, Remote Desktop, the push/keep-alive cards); screens never restate border, radius or background.
- `text-field.tsx` — `Field`, the one filled text input of the write forms (single line or growing multiline, mono, `autoFocus`/`maxLength`/`onSubmit` for save-on-Done); `approval-card.tsx` — `ApprovalCard`, an Assistants approval worded by the core with Approve / Deny that echo the card's own `actionHash` (expired cards cannot be answered).
- `avatar.tsx` — `Avatar` / `AvatarStack`, the Assistants' identity mark (hue follows the stable id).
- `motion.tsx` — shared motion: `Reveal` (ease in/out, staggered, capped by `motion.maxAnimated`), `Fade`, `Spin` (a turning glyph), `Chevron`, `ProgressBar`, `Skeleton`, `PulseRing`. Durations come from `motion` tokens; loops stop under reduced motion. `skeletons.tsx` — `ListSkeleton`, the loading shape of the thread lists. `pull-refresh.tsx` — `pullRefresh(refreshing, onRefresh)`: a factory (RN clones the element and nests the ScrollView in it, so it must be a real RefreshControl, never a wrapper component). `keyboard-inset.tsx` — the one keyboard-avoidance wrapper (reanimated `useAnimatedKeyboard`), never KeyboardAvoidingView.

Threads, hosts and workspaces:
- `thread-row.tsx` — `ThreadRow` (two-line `card` for an active chat with host + agent, one-line `slim` for a settled one), `WorkspaceBadge`, `ProviderBadge`, `StatusLabel`, `ProviderMark`: the one row of every thread list (Chats, Sessions, Workspace). `agent-groups.tsx` — `AgentGroups`, Needs you / Working / Idle as a `Shelf` over `ThreadRow`s: the "choose an agent" list of Share to Solco.
- `chats-filter-menu.tsx` — `ChatsFilterMenu`, the filter popover (main view with Host › and Workspace ›). `host-choices.tsx` — `HostChoices`, the Host submenu's rows: COMPUTERS (paired Macs), HERDR SESSIONS and DEVICES; "Host" means where the phone is looking.
- `host-card.tsx` — `HostCard`, the Mac's grouped card on the Hosts page (tile, name, live status, one chip per route; a tap opens the page's host sheet — switch / reconnect / forget — the card itself carries no buttons) and `toneColor` (status tone → token color).
- `keep-alive-card.tsx` — the Android-only keep-alive card (allow notifications, 5 s test alert on the agent channel, skip battery optimization); renders null on Web/iOS. Both cards now live on Settings → Notifications (`app/notifications.tsx`).

New chat and launching:
- `launch-pickers.tsx` — `Chip`, `FolderSheet`, `AgentSheet`: the workspace/agent choosers shared by `/compose` and `launch-composer`. `new-chat-hero.tsx` — `NewChatHero`, the native "What should we build in <workspace>?" centre drawn over the shared Chat page's empty draft (a `box-none` overlay that fades under the keyboard). `launch-composer.tsx` — the always-open light new-session form of Share to Solco and Automations' "Let an Agent Draft": workspace chip, Agent/Terminal mode, agent chip, prompt, send; an agent send with Chat served navigates at once to the pending Chat screen (`pending-<requestId>`, which runs the one `client.launch`).

Chat, Terminal and Git:
- `chat/chat-page-view.tsx` (+ `.web.tsx`) — host of the shared Chat page (and, with `route="feedback"`, of the Feedback inbox of the same bundle): react-native-webview (iframe on Web) loading `CHAT_PAGE_HTML` offline with the `mygo` shim; page calls → `onCall`, each state → `chat:updated` **after commit via React effect** (no injected JS while rendering); WebView load/reload resets readiness, onLoadEnd replays latest frame and opens requested subagent once; web links leave for the system browser.
- `ghostty-terminal.tsx` — THE phone terminal renderer (2026-11-07: Ghostty is the default, the header switch and `EXPO_PUBLIC_TERMINAL_RENDERER` are gone; Android carries `patches/expo-libghostty.patch`: a drag with no local scrollback sends PgUp/PgDn): the same handle/props over `expo-libghostty` (Ghostty VT parser; Metal on iOS, Canvas on Android; the library owns IME, touch selection, scrollback and its own key accessory bar). `focus/blur/toLive/resize` are no-ops, `onScrollBottom` never fires. Picked on the terminal screen by a header chip (xterm ⇄ Ghostty). Android also gets `fixedGrid` (same patch): the view pins its grid to the Mac pane's size and becomes a window onto it (horizontal drag pans, the window sits at the bottom and follows the cursor), because Herdr's observer only windows the pane's screen. Takeover scrolling (2026-11-07): the patch adds `remoteScroll`/`onScrollLines/onTap` (finger-following whole lines with fling momentum, positive = older); the wrapper turns it on when `onScrollLines` is given. Round 2: `themeColors` prop; `onMouse` + `remoteMouse` (drag→mouse); a tap on a visible http(s) URL offers to open it (patched view).
- `terminal-key-row.tsx` — the terminal's one scrollable key row (fires on lift so a scrolling swipe never types; held arrows/paging fire after 140 ms then repeat, Ctrl/Alt toggles); the library's own Android row is hidden through the patched `accessoryBar={false}`. Round 2: an `Fn` key swaps the row for F1–F12; a `Mouse` toggle (takeover only) turns drags into `{t:mouse}`.
- `terminal-style-sheet.tsx` — the terminal ⋮ menu's Font & theme sheet (OptionSheet): a 44 dp round −/+ font stepper and the five themes (swatch, name, check).
- `terminal-switch-sheet.tsx` — the ⋮ menu's Terminals sheet: every terminal of the Mac's workspaces (workspace badge, pane title, workspace · tab, check on this one; `router.replace` through `paneRoute`).
- `terminal-snippets-sheet.tsx` — the composer bookmark's Snippets sheet (OptionSheet): saved snippets and this session's recent lines in mono (tap = into the composer, ▶ run, ＋ save, × remove).
- `page-scroll-rail.tsx` — iOS only (Android's patched libghostty pages on any drag): a 22 px transparent strip on the terminal's right edge: dragging it sends PgUp (drag down) / PgDn (drag up), one page per 72 px (`lib/page-keys.ts`), so a full-screen TUI such as OMP scrolls its own pages; the native view's touches cannot be intercepted, so only the strip is captured. With `onLines` (takeover) it scrolls line by line (18 px per line) instead of paging.
- `files-view.tsx` — `FilesTree`, the Workspace's read-only file tree (folders first, children load in place).
- `files-search.tsx` — `FilesSearchResults`, the Files screen's file-name search body (needs `capabilities.filesSearch`): the Host's ranked hits as two-line rows (name over folder path, the typed words marked), a note when more matched than fit, and the loading / no-match / failed faces; takes the tree's place while the bar's search holds text.
- `status-badge.tsx` — the one-letter Git change badge (M/A/D/R/U/!). `diff-card.tsx` — `DiffCard`, one file's unified diff (hunk rows, old/new line numbers, highlighted tokens from `features/host/syntax`). `commit-sheet.tsx` — `CommitSheet`, the one multiline commit-message sheet (first line = subject, the rest the body) behind Commit and Commit & push; drawn through `Screen`'s `overlay`.
- `assistant-dock.tsx`（2026-11-07）：Assistant 聊天窗口 composer 上方的停靠区——待批准的 approval（Approve / Deny，同桌面）+ 任务结果卡（来自 Host 的 Assistant 页 `results`，即核心 `assistant results` 的同一投影；标题、状态、Open pane，窗格在树里才给；`results-store` 记叉掉）；纯 Solco 事实，不经模型、不进对话转录。

Remote Desktop and system cards:
- `remote-desktop/` — Remote Desktop's screens: `remote-surface.tsx` (the Mac's picture on a surface laid out once at the frame's pixel size, zoom/pan as a UI-thread transform of it plus a decay fling — never a per-frame relayout, which reallocates the Android surface buffer and lags — over a transparent touch layer, where a tap on the black bars toggles the menus instead of clicking, feeding `GestureEngine`, plus the trackpad cursor), `remote-live.tsx` (the session screen: auto-hiding top row — End, link line, landscape — and bottom dock — Windows = Mission Control, Desktop = Show Desktop, Type, Keys, More —, a floating touch/trackpad button, key panel and compose bar docked above the soft keyboard via `KeyboardDock`, options sheet for pointer mode / Show Mac pointer (`cursor.set`) / quality / display / landscape / stats / clipboard, notices, keep-awake), `remote-controls.tsx` (the sheet's shared rows: `Group`, `ToggleRow` on the platform Switch, `SegmentedRow`, `ChoiceRow`, `ActionRow`), `remote-keyboard.tsx` (`KeyPanel` and `ComposeBar`: Unicode/IME/dictation as `text.insert`, ⏎ and ⌫ as keys; long-pressing a shortcut pins it to the quick-key row above the dock). `remote-live.tsx` also carries the pinned quick-key row and the clipboard "Sync automatically" switch. Privacy/lock (2026-11-03): the live menu's "Mac screen" group toggles the Mac's blackout (`privacy.set`), and `session.state.locked` raises a lock banner (menus come up) with an Unlock button when `canUnlock` (`unlock.request`; the password lives on the Mac only). Update 2026-11-03: `virtual-keyboard.tsx` is the full on-screen Mac keyboard, kept short (2026-11-03 round 2: 28/34 px caps, 3 px gaps, four-row swipeable pages — main letters/numbers/esc ⇥ ⇧ ⏎ ⌫ , . /, symbols & F1–F12 & navigation, shortcuts — over ONE fixed bottom row ⌃⌥⌘ space ←↓↑→ plus the page key that names the next page, no page dots; ⌃⌥⌘⇧ latch once/locked and combine, keys fire on release so a page swipe never types, hold = repeat, long-press a shortcut pins it) replacing the old key strip; `drag-button.tsx` is the draggable Touch/Trackpad button (snaps to the nearest side edge, place saved in prefs); while a keyboard panel is open the picture shrinks into the free area; a lost link keeps the session screen up with the frozen picture dimmed and a "Reconnecting to your Mac…" pill (from attempt 2 a line names why the last try failed).
- `system-push-card.tsx`（2026-11-05）：Android Settings → Notifications 页面里一个明确 Opt-in 的系统推送开关。先请求 OS 通知权限再取得 ExpoPushToken（EAS project ID + FCM v1 必须真实存在），用已配对 Host 的 ScopeManage register/disable；无配置时只提供说明，已有本地提醒照常工作。提供不含 Assistant 数据的 Send test 按钮；不把 Expo queued 当成手机已收到。

Rule: components are presentation owners. Host queries, provider/session files, Herdr focus, and runtime lifecycle stay in feature controllers/services.
